
# Freelance Income Analyzer

A beginner-friendly Python project for analyzing freelance income using NumPy.

## Overview

Freelance Income Analyzer is a simple command-line application that calculates income statistics and tracks progress toward a financial goal.

This project is part of my Machine Learning learning journey.

## Features

- Calculate total income
- Calculate average income
- Find the highest income
- Calculate remaining financial target
- Display percentage of target achieved

## Technologies

- Python 3
- NumPy

## Sample Dataset

| Project | Income (IDR) |
|---------|-------------:|
| Project 1 | 200,000 |
| Project 2 | 350,000 |
| Project 3 | 150,000 |
| Project 4 | 500,000 |
| Project 5 | 700,000 |

Note: All income values are simulated for educational purposes.

## How to Run

Install NumPy:

    python3 -m pip install numpy

Run the application:

    python3 main.py
